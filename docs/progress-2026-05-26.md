# 2026-05-26 目前進度報告

日期：2026-05-26  
專案：RC Helium Balloon Blimp / 氦氣飛船馬達控制原型

## 1. 專案目標

本專案目前目標是製作一台以 ESP32-C3 SuperMini 為主控板的氦氣飛船原型，使用 DRV8833 馬達驅動模組控制左右兩顆 720 空心杯馬達。透過左右馬達不同推力，讓飛船可以完成前進、後退、左轉與右轉。

目前階段重點不是完整遙控，而是先確認「雙馬達差速控制」是否穩定可用。

## 2. 目前硬體配置

目前使用的主要零件如下：

| 零件 | 用途 |
| --- | --- |
| ESP32-C3 SuperMini | 主控板 |
| DRV8833 馬達驅動模組 | 控制左右兩顆馬達 |
| 720 空心杯馬達 x 2 | 左右推進馬達 |
| 104 陶瓷電容 x 2 | 降低馬達雜訊 |
| 100uF 電解電容 | 穩定馬達電源 |
| 外接馬達電池 | 提供馬達電源 |

## 3. 目前接線狀態

### ESP32-C3 SuperMini 與 DRV8833

| ESP32-C3 SuperMini | DRV8833 | 說明 |
| --- | --- | --- |
| GPIO4 | IN1 | 左馬達控制腳 1 |
| GPIO5 | IN2 | 左馬達控制腳 2 |
| GPIO6 | IN3 | 右馬達控制腳 1 |
| GPIO7 | IN4 | 右馬達控制腳 2 |
| 3V3 | EEP | 啟用 DRV8833 |
| GND | GND | 共地 |

### 馬達與電源

| DRV8833 | 連接位置 |
| --- | --- |
| VCC | 馬達電池正極 |
| GND | 馬達電池負極 |
| OUT1, OUT2 | 左馬達 |
| OUT3, OUT4 | 右馬達 |

ESP32-C3 的 GND、DRV8833 的 GND、馬達電池負極需要共地，否則控制訊號可能不穩定。

## 4. 電容安裝規劃

| 電容 | 安裝位置 | 目的 |
| --- | --- | --- |
| 104 陶瓷電容 | 並聯在左馬達兩端 | 降低馬達電刷雜訊 |
| 104 陶瓷電容 | 並聯在右馬達兩端 | 降低馬達電刷雜訊 |
| 100uF 電解電容 | 接在 DRV8833 VCC 與 GND 之間 | 穩定馬達供電 |

104 陶瓷電容沒有正負極。100uF 電解電容有正負極，正極接 DRV8833 VCC，負極接 DRV8833 GND。

目前程式已從原本的 Dabble 手機藍牙遙控測試，改成 DRV8833 雙馬達差速測試程式。

目前主要程式檔案：

| 檔案 | 狀態 |
| --- | --- |
| `src/main.cpp` | PlatformIO 主要編譯入口，目前是雙馬達差速測試版 |

目前 PlatformIO 設定如下：

```ini
[env:esp32-c3-supermini]
platform = espressif32
board = esp32-c3-devkitm-1
framework = arduino
upload_port = COM10
monitor_port = COM10
monitor_speed = 115200
```

## 6. 目前測試程式內容

目前韌體會自動循環執行以下動作：

1. 前進：左右馬達同時以速度 `150` 正轉 1.5 秒。
2. 停止 2 秒。
3. 後退：左右馬達同時以速度 `150` 反轉 1.5 秒。
4. 停止 2 秒。
5. 左轉：左馬達速度 `80`，右馬達速度 `170`，持續 1.5 秒。
6. 停止 2 秒。
7. 右轉：左馬達速度 `170`，右馬達速度 `80`，持續 1.5 秒。
8. 停止 3 秒，然後重複。

目前 PWM 速度設定：

```cpp
const int CRUISE_SPEED = 150;
const int TURN_SLOW_SPEED = 80;
const int TURN_FAST_SPEED = 170;
```

PWM 範圍是 `0` 到 `255`。目前速度設定偏保守，適合桌上測試與初期調機。

## 9. 安全注意事項

- 初期測試建議不要安裝螺旋槳，避免馬達突然轉動造成危險。
- 每次測試完應拔除馬達電池。
- 如果 DRV8833、馬達或電池明顯發熱，應立即斷電。
- 不建議讓目前自動測試程式長時間連續運轉。
- 裝上螺旋槳前，應先確認馬達方向與轉向邏輯。

## 10. 下一步建議

1. 用 VS Code PlatformIO 或可用的 PlatformIO CLI 重新 Build，確認目前程式可編譯。
2. 上傳到 ESP32-C3，觀察序列埠輸出是否依序顯示 Forward、Backward、Turn left、Turn right。

4. 若方向相反，先交換馬達線或調整 `setMotor()` / `turnLeft()` / `turnRight()` 的控制邏輯。
5. 將馬達固定到飛船架構後，重新測試推力方向。
6. 調整 `CRUISE_SPEED`、`TURN_SLOW_SPEED`、`TURN_FAST_SPEED`，找出穩定且不過熱的速度。
7. 馬達控制穩定後，再加入手機藍牙或其他遙控方式。
