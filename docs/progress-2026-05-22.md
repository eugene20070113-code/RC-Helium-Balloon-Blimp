# Progress Report - 2026-05-22

Date: 2026-05-22

## English

### Project

RC Helium Balloon Blimp motor-control prototype.

This stage focused on confirming that the ESP32-C3 SuperMini can control two 720 coreless motors through the DRV8833 motor driver. The firmware was upgraded from single-motor testing to two-motor differential thrust testing.

### Hardware Used

- ESP32-C3 SuperMini
- DRV8833 motor driver module
- Two 720 coreless motors
- 104 ceramic capacitors
- 100uF electrolytic capacitor
- External motor battery

### Wiring Status

The control wiring remains the same as the previous test:

| ESP32-C3 SuperMini | DRV8833 |
| --- | --- |
| GPIO4 | IN1 |
| GPIO5 | IN2 |
| GPIO6 | IN3 |
| GPIO7 | IN4 |
| 3V3 | EEP |
| GND | GND |

Motor and power wiring:

| DRV8833 | Connection |
| --- | --- |
| VCC | Motor battery positive |
| GND | Motor battery negative |
| OUT1, OUT2 | Left motor |
| OUT3, OUT4 | Right motor |

The ESP32-C3 GND, DRV8833 GND, and motor battery negative are connected together as a shared ground.

### Added Protection Components

| Component | Placement | Purpose |
| --- | --- | --- |
| 104 ceramic capacitor | Across the left motor terminals | Reduce motor electrical noise |
| 104 ceramic capacitor | Across the right motor terminals | Reduce motor electrical noise |
| 100uF electrolytic capacitor | Between DRV8833 VCC and GND | Stabilize motor power input |

The 104 ceramic capacitors do not have polarity. The 100uF electrolytic capacitor has polarity: positive to DRV8833 VCC and negative to DRV8833 GND.

### Firmware Update

The firmware was upgraded from individual motor testing to differential thrust testing.

Updated files:

- `src/main.cpp`
- `arduino/sketch_may14a/sketch_may14a.ino`
- `README.md`

The current firmware uses PWM speed control. PWM allows the motors to run at different thrust levels instead of only fully on or fully off.

Current speed settings:

```cpp
const int CRUISE_SPEED = 150;
const int TURN_SLOW_SPEED = 80;
const int TURN_FAST_SPEED = 170;
```

The PWM range is `0` to `255`.

### Current Test Sequence

1. Forward: left and right motors both run forward at speed `150` for 1.5 seconds.
2. Stop for 2 seconds.
3. Backward: left and right motors both run backward at speed `150` for 1.5 seconds.
4. Stop for 2 seconds.
5. Turn left: left motor runs at speed `80`, right motor runs at speed `170` for 1.5 seconds.
6. Stop for 2 seconds.
7. Turn right: left motor runs at speed `170`, right motor runs at speed `80` for 1.5 seconds.
8. Stop for 3 seconds.

### Test Result

The updated firmware was compiled and uploaded to the ESP32-C3 through PlatformIO on COM10.

- Compilation: successful
- Upload: successful
- Board detected as ESP32-C3
- Current program appeared to run normally during motor testing

The motors responded normally, so the basic dual-motor control stage is considered working.

### Important Notes

- Do not leave the test program running continuously for a long time.
- Disconnect the motor battery after confirming the test sequence.
- During early tests, do not install propellers.
- If the left and right turn directions are reversed, either swap motor wiring or adjust the `turnLeft()` and `turnRight()` speed values in the firmware.

### Next Steps

1. Confirm the 104 capacitors and 100uF capacitor are installed correctly.
2. Test the same sequence with the motors physically mounted on the blimp frame.
3. Confirm actual thrust direction with propellers installed carefully.
4. Tune `CRUISE_SPEED`, `TURN_SLOW_SPEED`, and `TURN_FAST_SPEED`.
5. Add remote-control logic after the motor behavior is stable.

## 中文

### 專案

RC 氦氣飛船馬達控制原型。

本階段主要確認 ESP32-C3 SuperMini 是否能透過 DRV8833 馬達驅動模組控制兩顆 720 空心杯馬達。同時將程式從單顆馬達測試升級成雙馬達差速推力測試。

### 使用硬體

- ESP32-C3 SuperMini
- DRV8833 馬達驅動模組
- 兩顆 720 空心杯馬達
- 104 陶瓷電容
- 100uF 電解電容
- 外接馬達電池

### 接線狀態

控制線維持上次測試的接法：

| ESP32-C3 SuperMini | DRV8833 |
| --- | --- |
| GPIO4 | IN1 |
| GPIO5 | IN2 |
| GPIO6 | IN3 |
| GPIO7 | IN4 |
| 3V3 | EEP |
| GND | GND |

馬達與電源接法：

| DRV8833 | 接法 |
| --- | --- |
| VCC | 馬達電池正極 |
| GND | 馬達電池負極 |
| OUT1, OUT2 | 左馬達 |
| OUT3, OUT4 | 右馬達 |

ESP32-C3 的 GND、DRV8833 的 GND、馬達電池負極已規劃接在一起，形成共地。

### 新增保護與穩定元件

| 元件 | 位置 | 作用 |
| --- | --- | --- |
| 104 陶瓷電容 | 並聯在左馬達兩端 | 降低馬達電氣雜訊 |
| 104 陶瓷電容 | 並聯在右馬達兩端 | 降低馬達電氣雜訊 |
| 100uF 電解電容 | 接在 DRV8833 VCC 與 GND 之間 | 穩定馬達電源輸入 |

104 陶瓷電容沒有正負極。100uF 電解電容有正負極，正極接 DRV8833 VCC，負極接 DRV8833 GND。

### 程式更新

本次將程式從單顆馬達測試升級成雙馬達差速推力測試。

更新檔案：

- `src/main.cpp`
- `arduino/sketch_may14a/sketch_may14a.ino`
- `README.md`

目前程式使用 PWM 速度控制。PWM 可以讓馬達以不同推力運轉，而不是只有全開或全關。

目前速度設定：

```cpp
const int CRUISE_SPEED = 150;
const int TURN_SLOW_SPEED = 80;
const int TURN_FAST_SPEED = 170;
```

PWM 數值範圍是 `0` 到 `255`。

### 目前測試流程

1. 前進：左右馬達都以速度 `150` 正轉 1.5 秒。
2. 停止 2 秒。
3. 後退：左右馬達都以速度 `150` 反轉 1.5 秒。
4. 停止 2 秒。
5. 左轉：左馬達速度 `80`，右馬達速度 `170`，持續 1.5 秒。
6. 停止 2 秒。
7. 右轉：左馬達速度 `170`，右馬達速度 `80`，持續 1.5 秒。
8. 停止 3 秒。

### 測試結果

已透過 PlatformIO 將更新後的程式編譯並燒錄到 COM10 上的 ESP32-C3。

- 編譯：成功
- 燒錄：成功
- 板子辨識為 ESP32-C3
- 馬達測試時目前看起來正常運作

兩顆馬達都有正常反應，因此目前可以視為雙馬達基本控制階段已經成功。

### 注意事項

- 不要讓測試程式長時間連續運轉。
- 確認測試流程後，請拔掉馬達電池。
- 初期測試時不要安裝螺旋槳。
- 如果左右轉方向相反，可以對調馬達線，或調整程式中的 `turnLeft()` 和 `turnRight()` 速度設定。

### 下一步

1. 確認 104 陶瓷電容和 100uF 電解電容安裝正確。
2. 將馬達固定到飛船架構上，再測試同樣流程。
3. 小心安裝螺旋槳後，確認實際推力方向。
4. 調整 `CRUISE_SPEED`、`TURN_SLOW_SPEED`、`TURN_FAST_SPEED`。
5. 馬達行為穩定後，再加入遙控控制邏輯。
