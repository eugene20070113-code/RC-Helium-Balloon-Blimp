# Progress Report - 2026-05-22

## Project

RC Helium Balloon Blimp motor-control prototype.

This stage focused on confirming that the ESP32-C3 SuperMini can control two 720 coreless motors through the DRV8833 motor driver, then upgrading the test program from single-motor testing to two-motor differential thrust testing.

## Hardware Used

- ESP32-C3 SuperMini
- DRV8833 motor driver module
- Two 720 coreless motors
- 104 ceramic capacitors
- 100uF electrolytic capacitor
- External motor battery

## Wiring Status

The control wiring remains the same as the previous test:

| ESP32-C3 SuperMini | DRV8833 |
| --- | --- |
| GPIO4 | IN1 |
| GPIO5 | IN2 |
| GPIO6 | IN3 |
| GPIO7 | IN4 |
| 3V3 | EEP |
| GND | GND |

Motor and power wiring:

| DRV8833 | Connection |
| --- | --- |
| VCC | Motor battery positive |
| GND | Motor battery negative |
| OUT1, OUT2 | Left motor |
| OUT3, OUT4 | Right motor |

The ESP32-C3 GND, DRV8833 GND, and motor battery negative are connected together as a shared ground.

## Added Protection Components

The following components were prepared for noise reduction and power stability:

| Component | Placement | Purpose |
| --- | --- | --- |
| 104 ceramic capacitor | Across the left motor terminals | Reduce motor electrical noise |
| 104 ceramic capacitor | Across the right motor terminals | Reduce motor electrical noise |
| 100uF electrolytic capacitor | Between DRV8833 VCC and GND | Stabilize motor power input |

The 104 ceramic capacitors do not have polarity. The 100uF electrolytic capacitor has polarity: positive to DRV8833 VCC, negative to DRV8833 GND.

## Firmware Update

The firmware was upgraded from individual motor testing to differential thrust testing.

Updated files:

- `src/main.cpp`
- `arduino/sketch_may14a/sketch_may14a.ino`
- `README.md`

The current firmware uses PWM speed control. PWM allows the motors to run at different thrust levels instead of only fully on or fully off.

Current speed settings:

```cpp
const int CRUISE_SPEED = 150;
const int TURN_SLOW_SPEED = 80;
const int TURN_FAST_SPEED = 170;
```

The PWM range is `0` to `255`.

## Current Test Sequence

The test program repeatedly performs the following sequence:

1. Forward: left and right motors both run forward at speed `150` for 1.5 seconds.
2. Stop for 2 seconds.
3. Backward: left and right motors both run backward at speed `150` for 1.5 seconds.
4. Stop for 2 seconds.
5. Turn left: left motor runs at speed `80`, right motor runs at speed `170` for 1.5 seconds.
6. Stop for 2 seconds.
7. Turn right: left motor runs at speed `170`, right motor runs at speed `80` for 1.5 seconds.
8. Stop for 3 seconds.

## Test Result

The updated firmware was compiled and uploaded to the ESP32-C3 through PlatformIO on COM10.

Upload result:

- Compilation: successful
- Upload: successful
- Board detected as ESP32-C3
- Current program appeared to run normally during motor testing

The motors responded in a way that looked normal, so the basic dual-motor control stage is considered working.

## Important Notes

- Do not leave the test program running continuously for a long time.
- Disconnect the motor battery after confirming the test sequence.
- During early tests, do not install propellers.
- If the left and right turn directions are reversed, either swap motor wiring or adjust the `turnLeft()` and `turnRight()` speed values in the firmware.
